## 2. 版本与适用范围

### UIUE 设计技术规范总册

- 版本：3.0.0。
- 适用：移动云软件产品 Web、PC 和移动端界面设计及研发过程。
- 关键原则：普适、多元、共生、开放；视觉设计的亲密性、对齐、重复、对比；规范样式优先，特殊场景需协商扩展。
- 规范结构：总册、Web 组件、典型页面、国际版、移动端、交互分册。

### 交互设计分册

- 封面版本：3.0.0；编制历史中的交互内容版本 1.1.0，更新时间 2025-07-31。
- 适用：Web 和移动端交互设计。
- 内容：易学、易操作、清晰、高效、一致；15 条基础原则、42 条落实标准、31 项走查内容。

### Web 端组件库样式分册

- 版本：3.0.0。
- 适用：国内 Web 端全局样式、基础组件、AI 组件、表单和加载交互。
- 设计基线：主品牌色 `#1A6AFF`，24 栅格，4px 间距基数等。

### 国际版设计分册

- 版本：3.0.0；编制历史首次发布 2025-08-15。
- 适用：国际版 Web 全局样式、组件、控制台和订购类典型页面。
- 设计基线：主品牌色 `#337DFF`，San Francisco 优先，1366 画板，1200px 最小有效内容区等。

### 原用户体验验证专家 Word

- 核心理念：不验证功能是否存在，只验证用户是否成功。
- 六维度：可发现、可理解、可操作、可预期、可恢复、高效。
- 分级：P0-P4。
- 流程：目标识别、旅程拆解、风险扫描、问题归因、结论。
- 本 skill 在此基础上新增证据门禁、规范分层、可访问性、国际化、AI、实现态、正向证据、复测和结构校验。

## 4. 规则冲突与协调

### 国内与国际主色

- 国内 Web：`#1A6AFF`。
- 国际版：`#337DFF`。

先确认版本，不可混用。

### 页面基线

- 国内组件分册：最小输出 1440×900，前端最小适配 1366×768。
- 国际版：1366 画板，有效内容区最小 1200px，兼容 1366×768 及以上。

按目标版本和批准实现基线判断。若产品采用现代响应式体系但要求 UIUE 合规，应记录批准例外或差异。

### 消息显示时间

- Web 组件分册：全局提示默认约 3 秒。
- 交互分册：需要用户识别的信息应大于 5 秒，交互后重新计时。

协调方式：非关键短反馈可使用默认时长；需阅读、修复、决策或承担风险的信息使用 5 秒以上、页面内常驻或手动关闭。

### 加载时间

- 交互分册：过渡动画宜 400ms 以内。
- Web 组件分册：业务加载按 <1s、1-2s、2-10s、>10s 分段处理；超过 4 秒的任务需明确预期。

协调方式：400ms 指过渡反馈，不代表业务必须在 400ms 完成。异步业务按等待时长管理预期。

### 规范与实际项目组件库

总册强调规范优先，但允许特殊业务场景协商新增、调整或扩展。因此：

1. 有批准例外：记录例外和适用范围；
2. 无批准例外：按偏离报告；
3. 规范未定义：按设计原则、项目 token 和任务成功判断；
4. 旧版项目：区分“存量债务”和“本次变更引入”。

## 5. 运行时使用原则

- 若用户提供更新版本规范，以更新材料为主并修订本 skill。
- 引用精确数值前，确认适用的是国内、国际、Web 还是移动端。
- 对需要图例才能判断的组件状态，打开对应 PDF 页面，不从文字摘要推断视觉细节。
- references 中的“专家扩展”不是原规范原文，报告时标为 `heuristic`。
- 不宣称本 skill 代表全部 WCAG、安全、隐私、真实用户研究或正式验收规范。
